# UI/UX Designer Skill

This skill enforces intentional, high-craft digital product design standards inspired by industry benchmarks (Linear, Raycast, Stripe, Apple, Vercel).

## Core Design Principles

1. **Information Hierarchy & Visual Weight**:
   - Primary data points (e.g., Job Title, Company, Compensation) receive distinct, immediate emphasis.
   - Metadata (source badges, dates, location tags) utilizes muted contrast and compact typographic styling.
   - Scannability: Users should absorb 10+ listings in seconds through clean layout alignment.

2. **Micro-interactions & Polish**:
   - Subtle spring or cubic-bezier hover transitions (150-200ms).
   - Crisp 1px borders (`rgba(255, 255, 255, 0.08)` or subtle light borders) rather than muddy drop shadows.
   - Distinct interactive feedback on click, active, focus-visible states.

3. **Color Theory & Atmosphere**:
   - Restrained palette: 90% neutral surfaces (deep zinc/slate or crisp white/gray), 10% intentional accent color.
   - Status indicators (e.g., Scraper Running, Applied, New) use standardized, accessible semantic palettes (emerald, amber, rose, sky).

4. **Data Density & Ergonomics**:
   - Drawer/side-sheet preview patterns allow deep inspection without losing scroll or filter position.
   - Clear filter pills with one-click dismiss and active counters.
